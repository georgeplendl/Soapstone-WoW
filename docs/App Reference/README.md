# App Reference

These docs describe **Soapstone the phone app**, not the WoW addon. They're
copied here as source material and are not kept in sync with the app repo.

Treat them as background: the addon borrows the core idea (messages you can
only read where they were left), but decisions here (voice recording, a 1-mile
gate, Sign in with Apple/Google, Supabase, personas) don't automatically apply
in Azeroth.

- `DESIGN.md`: technical design for the app
- `Soapstone — App Specification.md`: screen-by-screen UX spec
- `MVP - Draft.md`: app MVP scope and locked decisions
- `Open Questions.md`, `Flows.md`: app UX open questions and flows
- `Discovery-Plan-Build-Kill.md`: build/kill validation plan for the app
- `Research/`: personas, empathy and journey maps, jobs-to-be-done (for phone users)
